# Glossary

| Term | Meaning |
|---|---|
| **Act 586** | Private Healthcare Facilities and Services Act 1998 — registration regime for private clinics (see PHFSA) |
| **BNM** | Bank Negara Malaysia — central bank / insurance regulator |
| **CKAPS** | MOH's private medical practice control section; publishes the register of private clinics GRID uses as its authoritative spine |
| **CMA** | Communications and Multimedia Act 1998; s.233A (unsolicited commercial electronic messages, added 2025) not yet in force |
| **Golden record** | The single resolved `clinic` row assembled from all source sightings |
| **GP** | General practitioner / primary care — GRID's sole scope |
| **JPDP** | Jabatan Perlindungan Data Peribadi — Personal Data Protection Department/Commissioner |
| **KKM / MOH** | Kementerian Kesihatan Malaysia / Ministry of Health |
| **Klinik Umum** | "General clinic" — the CKAPS scope value identifying GP clinics; GRID's ground truth |
| **Klinik pergigian** | Dental clinic — out of scope |
| **MCO** | Managed care organisation |
| **MMC** | Malaysian Medical Council — practitioner registration (MMC numbers are personal data) |
| **MSIC** | Malaysia Standard Industrial Classification (business activity codes) |
| **PDPA** | Personal Data Protection Act 2010 (Act 709), amended 2024 |
| **PHFSA** | Private Healthcare Facilities and Services Act 1998 (Act 586) |
| **PNM** | PMCare's Provider Network Management team — GRID's user |
| **Queue A / Queue B** | New openings / existing registered GP clinics not on the PMCare panel |
| **SOCSO / PERKESO** | Social Security Organisation — its panel clinic list is a leading indicator |
| **SSM** | Suruhanjaya Syarikat Malaysia (Companies Commission) — never scraped |
| **TPA** | Third-party administrator — PMCare's role: neutral, not insurer, not clinician |
| **WP** | Wilayah Persekutuan (Federal Territory): Kuala Lumpur, Putrajaya, Labuan |
